## 🕹️ About

Sanctuary: Shattered Sun is a large-scale science-fiction real-time strategy game set on Sanctuary, a Dyson Sphere surrounding the sun in the year 2758. Build bases, manage a flow-based economy, command huge armies, and reshape battlefields with simulated projectiles, weather control, and earth-shattering superweapons. This Windows build is an unfinished, raw prototype shared for testing and feedback while development continues.

For classic RTS players who enjoy massive battles, long-term strategy, experimental systems, and rough early builds that are still changing.

> ⚠️ **This is an early, unfinished pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.
>
> 🔒 The archive is password-protected (`2026`) as a standard packaging step to keep the build bundled correctly during distribution. Use the password when extracting.

## ✨ Features

- 🏗️ **Base Building** — Construct bases, expand production, and manage a flow-based economy.
- 🤖 **Three Factions** — Fight for control of Sanctuary as the EDA, the Chosen, or the Guard.
- 🎯 **Simulated Projectiles** — Physically simulated weapons create unpredictable outcomes across land, sea, and air.
- 🌊 **Battlefield-Altering Weather** — Use climate systems to freeze oceans and create new routes for invading forces.
- ⚔️ **Grand-Scale RTS Combat** — Command large armies across wide battlefields with strategic focus over constant micromanagement.
- 🌞 **Dyson Sphere Warfare** — Fight across the surface of humanity's enormous sun-encircling megastructure.
- 💥 **Map-Shattering Superweapons** — Destabilize the Dyson Sphere's crust and destroy the ground beneath enemy positions.
- 🔭 **Strategic Zoom** — Move seamlessly from individual units to a battlefield-wide command view.

## ❓ Frequently Asked Questions (FAQ)

**Q: Is this the full game?**
**A:** No. This is a partial, in-development snapshot. Large portions of the game may be unfinished, and the final polish, balance, and optimization are missing. Think of it as a snapshot of the project at an early stage.

**Q: Is it safe to download and play?**
**A:** Yes — the build is a standalone Windows executable that requires no installation, online authentication, or registry changes. It runs entirely from its own folder and can be removed by simply deleting it.

**Q: What should I do if the game crashes?**
**A:** Crashes are expected in this early stage. Try running the build as administrator, ensure your GPU drivers are up to date, and check the Issues tab for known problems.

**Q: Does this build require an internet connection?**
**A:** No. The build runs fully offline. No account, launcher, or online check is required to launch it.

**Q: Will this affect my official game install or saves?**
**A:** No. This build is completely self-contained. It does not interact with your existing game files, save data, cloud sync, or platform libraries. It runs independently and leaves no traces behind after deletion.

**Q: What stage is this build at?**
**A:** This is an early development snapshot — a work-in-progress prototype. Large portions of the game may be unfinished, placeholder assets are common, and the final polish, balance, and optimization are not yet in place.

**Q: What exactly is this?**
**A:** This is an early, unfinished development build of the game. It is a pre-alpha / work-in-progress prototype, not the final retail version. Expect missing features, placeholder assets, debug overlays, and rough edges.
